# TTS/STT 统一结果视图设计

## 背景

当前 TTS 和 STT 是两个独立的 tab，TTS 生成后文字停留在输入框，需要切换 tab 才能看到句子。STT 则是音频 + 句子在同一视图。

用户期望：**不管用哪种方式输入，结果视图统一，交互一致。**

---

## 核心设计原则

**一个结果视图，两种输入方式。**

---

## 架构

### 两种输入模式，共用同一结果视图

| 模式 | 输入 | 过程 | 结果 |
|------|------|------|------|
| STT | 上传音频 | 转写（Deepgram 提供精确时间戳）→ 可微调 | 共用结果视图 |
| TTS | 输入文字 | 预览切分 → 生成音频 → ASR 获取精确时间戳 → 可调整 | 共用结果视图 |

### 关键流程

#### TTS 流程
1. **输入文字** → 实时按句子（. ! ?）切分预览
2. **用户微调切分点**（可选）
3. **点"生成语音"** → 调用 ElevenLabs
4. **音频生成后** → 自动调用 ASR（Deepgram）获取精确时间戳
5. **显示结果视图**（输入框消失）
6. **如需修改** → 点"重新生成"按钮，返回步骤1

#### STT 流程（保持不变）
1. **上传音频** → 自动转写
2. **显示结果视图**（已有精确时间戳）
3. **可微调切分点**

## 共用结果视图

### 布局（从上到下）

```
┌─────────────────────────────────────┐
│  音频播放条 + 控制按钮              │
│  [播放/暂停] [0.75x] [进度条] [保存]│
├─────────────────────────────────────┤
│  [重新生成] (TTS模式显示)           │
├─────────────────────────────────────┤
│  句子列表                           │
│  ┌─────────────────────────────────┐│
│  │ 0.0-2.5s  Sentence 1            ││
│  └─────────────────────────────────┘│
│  ┌─────────────────────────────────┐│
│  │ 2.5-5.1s  Sentence 2            ││
│  └─────────────────────────────────┘│
│  ...                                │
├─────────────────────────────────────┤
│  中文翻译（如果有）                  │
└─────────────────────────────────────┘
```

### 句子列表交互

| 交互 | 行为 |
|------|------|
| 点击句子 | 跳转到该句开始时间播放 |
| 播放中 | 当前句子高亮 |
| 点击时间戳 | 进入微调模式 |
| 微调模式 | 可拖拽或 +/- 按钮调整起止时间 |

### 状态

- **有音频 + 有句子**：显示完整结果视图
- **有音频 + 无句子**：显示音频播放条 + 转写按钮
- **无音频**：显示输入区域（TTS 或 STT 上传）

## TTS 特有交互

### 输入区域（生成前显示）

```
┌─────────────────────────────────────┐
│  [📝 文字转语音] [🎤 语音转文字]    │  ← 模式切换
├─────────────────────────────────────┤
│  输入文字...                        │  ← textarea
│                                     │
│  句子预览：                         │
│  • This is sentence one.            │
│  • This is sentence two?            │
│  • And this is third!               │
│                                     │
│  [🎵 生成语音]                      │
└─────────────────────────────────────┘
```

### 生成后

输入框消失，显示结果视图 + "重新生成"按钮。

---

## 微调切分点交互

### 交互方式

点击句子时间戳进入微调模式：

```
[ - ] [ 0.0 ]-[ 2.5 ]s [ + ]   [ - ] [ 5.1 ]-[ 7.3 ]s [ + ]
                     [ 保存 ] [ 取消 ]
```

或直接拖拽句子边界。

## 文件改动

### API 层
- `src/app/api/tts/route.ts`：保持不变（生成音频）
- `src/app/api/transcribe/route.ts`：TTS 生成后调用，获取精确时间戳
- 可能需要新增 API：`POST /api/tts/segment` 做文字切分预览

### 前端组件
- `src/app/topics/[id]/page.tsx`：重构 QuestionItem 组件
  - 移除 mode tab（TTS/STT 分开显示的设计）
  - 统一为：输入区 → 结果区的两阶段结构
  - 句子列表组件提取为独立子组件

### 状态结构

```typescript
interface QuestionState {
  // 输入阶段
  inputMode: 'tts' | 'stt';
  ttsInput: string;           // TTS 模式：文字输入
  ttsSegments: Segment[];     // TTS 模式：切分预览

  // 结果阶段
  audioUrl: string | null;
  sentences: Sentence[];       // 时间戳 + 文本
  isAdjusting: boolean;       // 是否在微调模式

  // 通用
  isGenerating: boolean;
  error: string | null;
}
```

---

## 实现顺序

1. **第一阶段**：TTS 模式重构
   - 文字输入 + 实时句子预览
   - 生成音频
   - 调用 ASR 获取时间戳
   - 显示结果视图

2. **第二阶段**：统一结果视图
   - STT 模式适配同一视图
   - 句子列表组件复用

3. **第三阶段**：微调功能
   - 时间戳点击微调
   - 拖拽调整切分点
